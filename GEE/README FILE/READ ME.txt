HOW TO USE THE GEE EARTH ENGINE TOOL FOR HABITAT CLASSIFICATION
------------------------------------------------------------------

1. Download the 3 JavaScript module files from GitHub.

-Module 1_Data Preparation.js
-Module 2_Classification and Segmentation.js
-Module 3_Graphic User Interface.js

2. Sign into your Google Earth Engine Account and open GEE Code Editor.

3. In your GEE Code Editor,  Create 3 new scripts and name them : 

	i) Module 1_Data Preparation.
	ii) Module 2_Classification and Segmentation.
	iii) Module 3_Graphic User Interface.

This will help to distinguish the purpose of each module.

4. In the first script, Import the sample boundary and rename it sample, then copy and paste the whole code from the downloaded Module 1_Data Preparation.js file

5. Run the code and Tasks making sure the predictor Stack and training Image are exported to your GEE Assets. 

6. Also run the tasks in the task tab to export all the Sentinel 1 and Sentinel 2 predictor variables for use in R.

7. In the second script, import the sample boundary and rename it sample and also import the provided training Polygons , then copy and paste the whole code from the downloaded Module 2_Classification and Segmentation.js file.

8. Run the code and in the Tasks tab  make sure the classified image, accuracy results and SNIC segments image are exported to your GEE Assets. 

9. In the last script, Import the sample boundary  and rename it sample, then copy and paste the whole code from the downloaded Module 3_Graphic User Interface.js file.

10. Run the code to view the habitat classification.
