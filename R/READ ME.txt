
HOW TO USE THE R SCRIPT FOR HABITAT CLASSIFICATION




1. Download all the predictor variables using GEE Module 1 script.
------------------------------------------------------------------

If using the sample dataset, the predictor variables are provided in the:

PREDICTOR_VARIABLES folder.




2. Download RGB training images from Copernicus website. 
---------------------------------------------------------

If using the sample dataset, the training images are provided in the:

TRAINING_IMAGES folder.



3. Prepare the Training Images
-------------------------------

*IMPORTANT – Raster Alignment*

Before performing segmentation, the downloaded RGB training images must be resampled and clipped using one of the predictor variables as the reference raster.

If using the sample dataset, this step has already been completed and does not need to be repeated.

The RGB training images and predictor variables must have the same:

-Number of rows
-Number of columns
-Spatial extent
-Coordinate reference system (CRS)
-Pixel/grid alignment

Using a predictor variable as the reference ensures that the training images are aligned with the predictor data.

This is important because the R script uses the segmented training images together with the predictor variables to calculate zonal statistics. If the rasters are not correctly aligned, the zonal statistics step may fail or produce incorrect results.




4. Digitise the habitats as polygon features for each of the training images
----------------------------------------------------------------------------

If using the sample dataset, the training polygons are provided in the:

TRAINING_POLYGONS folder.

*Ensure that the polygon files contain the required ClassID field used by the R script to identify the habitat class.





5. Open the r script 'Habitat_Classification_Internal_Validation.R'
   ------------------
Before running the script, adjust the file paths so that they correspond to the location of the folders on your own computer.




6. Run the code.
----------------
